01 — GEOMETRIC PULSE

Pure CSS animation — no JavaScript drives these shapes. Every rotation, pulse, and morph is achieved through @keyframes, clip-path transitions, and cubic-bezier timing functions.

The staggered wave effect emerges from carefully offset animation-delay values across the grid, proving that CSS alone can create complex, organic motion.

@keyframes clip-path mix-blend-mode cubic-bezier backdrop-filter @property

02 — FLOW FIELD

A flow field maps a direction to every point in space using a noise function. Thousands of particles follow these invisible currents, leaving semi-transparent trails that reveal the underlying mathematical structure.

The field evolves slowly over time as the noise offset shifts, creating an organic, ever-changing landscape of motion. Click anywhere to create a burst of turbulence.
